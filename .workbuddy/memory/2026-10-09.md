# 2026-10-09

## deploy/android-image：定制 Android 容器镜像方案（新建，独立于现有 Go/Python 代码）

为「Docker 中运行高度定制 Android」交付一套可落地方案，目录 `deploy/android-image/`。

### 选型结论
- 基座：**redroid/redroid:14.0.0-latest**（amd64 单架构基线；AOSP in Docker，共享宿主内核，**不需要 KVM**）。
  对比过 Damru / Waydroid / budtmo docker-android / Anbox / Cuttlefish 后选定。
- Damru（akwin1234/damru）本质是 **redroid 之上的 Python 自动化层**，不是容器方案；
  授权为 PolyForm Noncommercial 1.0.0，**商用需另授权** → 只借鉴思路，不引用代码、不装包。

### 核心机制（后续所有定制都建立在这两条上）
1. redroid 把 init 读内核 cmdline 的来源改成 `/proc/self/cmdline` → 任意 `ro.xxx=yyy` 容器参数在
   **init 阶段**写入属性系统。机型/指纹/品牌/ABI/GPU 全部运行时可配，**不需要 Magisk/resetprop/重建镜像**。
2. 只有 `ro.*` 能这么注入；`persist.*`（时区/语言）走生成的 `/system/etc/init/xphone.rc` 的 setprop。

### 架构（entrypoint.sh 为 PID 1，最后 exec /init）
- 开机前：复制字体/开机动画/系统 APK、生成 init.rc、清理痕迹、同步 build.prop、`exec /init "$@"`
- 开机后：`post-boot.sh` 在 `sys.boot_completed=1` 由 init.rc 触发（pm install、语言时区、电池伪装、init.d 钩子）
- 配置目录 `config/` 整体只读挂到 `/xphone`；`/data` 单独持久化。改配置只需 restart。

### 真机化加固（用户追加需求，对标 Damru 三层）
- OS 属性层：stealth 属性注入 + **`/system/build.prop` 文件面同步回写**（检测会读文件与 getprop 交叉比对，只改一边必露馅）
- 二进制层：自研 LD_PRELOAD hook 库 `native/xphone-fake/`（hook glGetString / openat /proc/meminfo、cpuinfo / sysconf / __system_property_get），
  **必须在 init.rc 的 `on early-init` 设置 LD_PRELOAD**，否则 zygote 已启动、子进程不继承。默认关闭。
- 硬件规格层：`config/fake/{meminfo,cpuinfo,props.map}` + `XFAKE_*` 变量，三个数字必须互相对齐。
- **硬约束：抗检测场景宿主必须是 arm64**；x86_64 的 `/proc/cpuinfo` 暴露 Intel/AMD，属性改再多也兜不住。
- 提供 `scripts/capture-props.sh`（从真机抓整套属性生成自洽 profile），不要手编 fingerprint。
- `scripts/stealth-audit.sh` 站在检测方视角列风险项。

### 同日追加：两个拍板项的实现（STEALTH_PRELOAD 安全启用 + SELINUX 默认 enforcing）
- **修了一个真 bug**：XFAKE_* 变量原本只在 entrypoint shell 里，Android 进程看不到。
  现在 entrypoint 生成 init.rc 时在 `on early-init` 同步 `setenv XFAKE_*`（含双引号包裹空格值，已模拟渲染验证）。
- hook 库加**双保险丝**：`config/fake/disable` 文件或 `XFAKE_DISABLE=1` → 全 hook 直通；
  紧急恢复 = 宿主 `touch config/fake/disable && docker restart`。
- hook 库 `sysconf` 改用 bionic 头文件真实宏（`_SC_NPROCESSORS_*` 等，带 `#ifdef` 保护），
  不再硬编码数字（glibc/bionic 取值不同，硬编码是雷）；补了 `<stdarg.h>`。clang 语法检查通过。
- 新增 `scripts/test-preload.sh`：`check` 免重启冒烟（push 到 /data/local/tmp 单进程测）→
  `--enable`（开开关+重启+看门狗等开机+验证，失败自动回滚 0）→ `--disable` 手动回滚。
- **SELINUX 默认改 enforcing**：entrypoint 用 canary 文件实测 chcon，xattr 不可用自动降级
  permissive + 日志告警；新增 `label()` 统一给字体/APK（含目录）/rc/hook 库/features.xml 打标签。
- verify.sh 增加 SELinux 状态检查与第 9 节 hook 生效校验（adbd 继承 LD_PRELOAD，adb shell 读
  /proc/meminfo 应返回伪造值）。
- 本机无 NDK（~/Library/Android/sdk 无 ndk 目录），未实际编译 .so。
